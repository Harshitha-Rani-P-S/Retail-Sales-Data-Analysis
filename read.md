# Retail Sales Data Analysis Using Python

## Project Overview

This project analyzes retail sales data using Python to identify important business trends and generate meaningful insights.

The project focuses on data cleaning, exploratory data analysis, statistical analysis, customer analysis, product analysis, regional performance, sales trends, profitability, and data visualization.

The Sample Superstore dataset was used for this project.

## Project Objectives

The main objectives of this project are:

* Import and understand retail sales data
* Clean and preprocess the dataset
* Handle missing values and duplicate records
* Perform exploratory data analysis
* Analyze sales and profit performance
* Identify top-performing products
* Identify high-value customers
* Analyze regional performance
* Study monthly sales trends
* Identify loss-making sub-categories
* Perform correlation analysis
* Generate meaningful business insights
* Create professional data visualizations

## Key Business Insights

### Category Performance

Technology generated the highest sales and profit.

Furniture generated high sales but comparatively low profit.

Office Supplies generated strong profitability and the highest quantity sold.

### Product Performance

The highest revenue-generating product was:

**Canon imageCLASS 2200 Advanced Copier**

Total Sales: approximately **61,599.82**

### Regional Performance

The West region generated the highest sales and profit.

West Sales: approximately **725,457.82**

West Profit: approximately **108,418.45**

The East region was the second strongest performing region.

### Customer Analysis

The highest revenue-generating customer was:

**Sean Miller**

Total Sales: approximately **25,043.05**

### Monthly Sales Trend

The highest monthly sales occurred in:

**November 2017**

Sales: approximately **118,447.83**

The lowest monthly sales occurred in:

**February 2014**

Sales: approximately **4,519.89**

### Underperforming Sub-Categories

The following sub-categories generated overall losses:

* Tables: approximately -17,725.48
* Bookcases: approximately -3,472.56
* Supplies: approximately -1,189.10

These sub-categories may require further analysis related to pricing, discounts, shipping costs, and profit margins.

### Correlation Analysis

Sales and Profit showed a moderate positive correlation of approximately **0.48**.

Discount and Profit showed a negative correlation of approximately **-0.22**.

This suggests that excessive discounting may negatively affect profitability.

This project demonstrates an end-to-end retail data analysis workflow using Python.

The analysis identified high-performing products and regions as well as loss-making sub-categories.

The project demonstrates how Python, Pandas, NumPy, Matplotlib, and Seaborn can be used to convert raw business data into useful insights for decision-making.
